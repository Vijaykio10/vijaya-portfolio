## Run the portfolio website locally

The website uses React, Vite, Tailwind CSS, and Framer Motion.

```bash
git clone https://github.com/Vijaykio10/vijaya-portfolio.git
cd vijaya-portfolio
npm install
npm run dev
```

Run `npm run build` to create a production build.
